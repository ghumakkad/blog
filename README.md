# Athāto Ghumakkad Jigyāsa Blog

A trekking and mountaineering blog built with [Jekyll](https://jekyllrb.com/) and the [Trophy](https://github.com/thomasvaeth/trophy-jekyll) theme by Thomas Vaeth. Deployed to [GitHub Pages](https://ghumakkad.github.io/blog).

## Prerequisites

- **Ruby 4.0.x** — install via [ruby-install](https://github.com/postmodern/ruby-install) or your preferred version manager
- **Bundler** — `gem install bundler`
- A Ruby version manager like [chruby](https://github.com/postmodern/chruby) is recommended

## Setup

```bash
# Clone the repository
git clone https://github.com/ghumakkad/blog.git
cd blog

# Install dependencies
bundle install
```

## Local Development

```bash
# Start the development server with live reload
bundle exec jekyll serve --livereload

# The site will be available at http://localhost:4000/blog/
```

Other useful commands:

```bash
# Build the site without serving (output goes to _site/)
bundle exec jekyll build

# Build with drafts visible
bundle exec jekyll serve --drafts

# Build with verbose output for debugging
bundle exec jekyll build --verbose

# Build with future-dated posts visible
bundle exec jekyll serve --future
```

## Writing a New Post

1. Create a new Markdown file in `_posts/` with the naming format:
   ```
   YYYY-MM-DD-title-slug.markdown
   ```

2. Add front matter at the top of the file:
   ```yaml
   ---
   layout: post
   title: "Your Post Title"
   date: YYYY-MM-DD
   categories: [trek, self]
   image: /assets/images/your-image.jpg
   ---
   ```

3. Write your content in Markdown (or AsciiDoc with `.adoc` extension).

4. Place any images in `assets/images/` and reference them in your post.

### Available Categories

Posts can be tagged with categories like `trek`, `course`, `mountaineering`, `organised`, `self`, and `blog`. Category pages are auto-generated by `_plugins/category_generator.rb`.

## Project Structure

```
├── _config.yml          # Jekyll configuration
├── _data/               # YAML data files (authors)
├── _includes/           # HTML template partials
├── _layouts/            # Page templates (default, post, compress)
├── _plugins/            # Custom Jekyll plugins
├── _posts/              # Blog posts (Markdown/AsciiDoc)
├── _sass/               # SCSS stylesheets
├── assets/              # CSS, JavaScript, images, fonts
├── Gemfile              # Ruby dependencies
├── .ruby-version        # Ruby version (4.0.2)
└── .github/workflows/   # GitHub Actions deployment
```

## Configuration

Site configuration lives in `_config.yml`. Key settings:

| Setting | Description |
|---------|-------------|
| `url` / `baseurl` | Site URL and path prefix (`/blog`) |
| `paginate` | Number of posts per page (default: 5) |
| `markdown` | Markdown engine (`kramdown`) |
| `plugins` | Active Jekyll plugins |
| `sass.style` | CSS output style (`compressed`) |

## Plugins

| Plugin | Purpose |
|--------|---------|
| `jekyll-paginate` | Paginates the post listing on the homepage |
| `jekyll-sitemap` | Generates `sitemap.xml` for search engines |
| `jekyll-asciidoc` | Allows writing posts in AsciiDoc format |
| `jemoji` | GitHub-style emoji support (`:emoji_name:`) |
| `jekyll-mentions` | Converts `@username` to Twitter links |
| `jekyll-avatar` | Displays GitHub user avatars |
| `jekyll-readme-index` | Uses README.md as index page when appropriate |
| `jekyll-seo-tag` | Adds SEO meta tags to pages |

## Deployment

The site deploys automatically to GitHub Pages via GitHub Actions on every push to `master`. The workflow is defined in `.github/workflows/jekyll-gh-pages.yml`.

No manual deployment steps are needed — just push to `master`.

## Updating Dependencies

```bash
# Update all gems to latest compatible versions
bundle update

# Update a specific gem
bundle update jekyll
```

## Tech Stack

- **Static Site Generator**: Jekyll 4.4
- **Ruby**: 4.0
- **Theme**: Trophy (vendored in `_sass/`, `_layouts/`, `_includes/`)
- **Syntax Highlighting**: CodeRay (AsciiDoc) / Rouge (Markdown)
- **Deployment**: GitHub Pages via GitHub Actions
- **Markup**: Markdown (kramdown) and AsciiDoc
